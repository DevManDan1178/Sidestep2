# Sidestep 2

Sidestep 2 is an early game-development project built with Unity and C#.

The project was created to explore the fundamentals of Unity development, gameplay programming, and building a complete playable game from the ground up.

## Overview

This project represents an early stage of my experience with Unity and C# and serves as a reference point for the progression of my game-development skills.

The repository contains the original Unity project, including its assets, project settings, packages, and C# scripts.

## Technical Highlights

- **Unity Development** — Built as a complete Unity game project.
- **C# Programming** — Gameplay functionality implemented using C# scripts.
- **Gameplay Programming** — Developed the core logic required to create a playable game.
- **Component-Based Architecture** — Used Unity's component-based development model.
- **Asset Management** — Organized game assets and project resources within Unity.
- **WebGL Deployment** — Exported the game for browser-based play.
